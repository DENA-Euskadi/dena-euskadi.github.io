## :material-clipboard-text: What to Include in Your Query

### For Technical Issues

- [ ] **Detailed description** of the problem
- [ ] **Environment** where it occurs (PRE/PRO/local)
- [ ] **Complete logs** of the error
- [ ] **Steps to reproduce** the problem
- [ ] **messageCorrelationId** if available
- [ ] **Relevant configuration** (without credentials)

### For Credential Requests

- [ ] **Administration name**
- [ ] **Contact person** and role
- [ ] **Requested environment** (PRE/PRO)
- [ ] **Use cases** to implement
- [ ] **Estimated timeline** for integration

### For Implementation Questions

- [ ] **Specific endpoint** being queried
- [ ] **Documentation** already reviewed
- [ ] **Specific use case**
- [ ] **Technology** you are using
