### Arazo Teknikoetarako

- [ ] Arazoaren **deskribapen zehatza**
- [ ] Gertatzen den **ingurunea** (PRE/PRO/lokala)
- [ ] Errorearen **log osoak**
- [ ] Arazoa **erreproduzitzeko urratsak**
- [ ] **messageCorrelationId** erabilgarri badago
- [ ] Gertatzen denaren testuingurua

### Kredentzial-eskaereetarako

- [ ] **Administrazioaren izena**
- [ ] **Kontaktu-pertsona** eta kargua
- [ ] **Eskatutako ingurunea** (PRE/PRO)
- [ ] Inplementatzeko **erabilera-kasuak**
- [ ] Integrazioaren **gutxi gorabeherako kronograma**

- [ ] Kontsultatutako **endpoint zehatza**
- [ ] Dagoeneko berrikusitako **dokumentazioa**
