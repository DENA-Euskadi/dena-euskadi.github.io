# Administración → CORE DENA

Cuando una administración realice una petición a DENA, deberá incluir un token OAuth 2.0 en la cabecera `Authorization: Bearer <token>`.

Para la obtención de este token, se generarán unas credenciales (client-id y client-secret) en DENA. La administración deberá configurar estas credenciales en su sistema y generar el token mediante un flujo client credentials.
