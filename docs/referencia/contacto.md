## :material-clipboard-text: Qué Incluir en tu Consulta

### Para Problemas Técnicos

- [ ] **Descripción detallada** del problema
- [ ] **Entorno** donde ocurre (PRE/PRO/local)
- [ ] **Logs completos** del error
- [ ] **Pasos para reproducir** el problema
- [ ] **messageCorrelationId** si está disponible
- [ ] **Configuración relevante** (sin credenciales)

### Para Solicitud de Credenciales

- [ ] **Nombre de la administración**
- [ ] **Persona de contacto** y cargo
- [ ] **Entorno solicitado** (PRE/PRO)
- [ ] **Casos de uso** a implementar
- [ ] **Cronograma** estimado de integración

### Para Dudas de Implementación

- [ ] **Endpoint específico** consultado
- [ ] **Documentación** ya revisada
- [ ] **Caso de uso concreto**
- [ ] **Tecnología** que estás usando
