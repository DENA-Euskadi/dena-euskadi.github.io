# :material-translate: LanguageTexts

## Deskribapena

Gako-balio mapa hizkuntza ezberdinetan testuak sartzeko. Zerbitzu-izenetan, prozeduretan, egoeretan, etab. erabiltzen da.

---

## JSON atributuak

| Gakoa | Mota | Deskribapena |
|---|---|---|
| `SPANISH` | `String` | Testua gaztelaniaz |
| `BASQUE` | `String` | Testua euskaraz |
| `ENGLISH` | `String` | Testua ingelesez (aukerakoa) |

---

## Adibidea

```json
{
    "SPANISH": "Cita previa para renovación de DNI",
    "BASQUE": "NAN berritzeko aurretiko hitzordua"
}
```

!!! tip "Gutxieneko hizkuntzak"

    Beti gutxienez **gaztelania** (`SPANISH`) eta **euskara** (`BASQUE`) sartzea gomendatzen da.
