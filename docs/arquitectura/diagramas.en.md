## How to edit

!!! tip "Editing with draw.io"

    1. Open [app.diagrams.net](https://app.diagrams.net/)
    2. Load the `.drawio` file from `docs/adjuntos/imagenes/drawio/`
    3. Make your changes
    4. Export as PNG to the `docs/adjuntos/imagenes/` directory
    5. Commit both files (`.drawio` + `.png`)
